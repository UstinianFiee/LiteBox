# 轻匣 LiteBox

**把常用工具，收进一个匣子。**

轻匣是一款面向个人日常工作与开发运维的 Windows 免安装工具箱，将文本整理、图片处理、格式转换、Markdown、远程连接、数据库、AI 助手和数据看板集中在统一的工作台中。

Windows x64 · 简体中文 / English · 蓝白浅色 / 黑灰深色 · 本地优先 · MIT

**简体中文** | [English](README.en.md)

## 功能概览

| 模块     | 功能                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------- |
| 工作台   | 工具搜索、收藏、最近使用、使用统计，以及可暂停的动画与中英名言轮播                                                  |
| 文本整理 | 自定义分隔符、按数量或组数分组、去重、引号处理、交集与差集、复制与导出；保留前导零和超长编号                        |
| SQL 处理 | 将多行文本填入 SQL `IN` 条件，处理空行和引号转义，支持去重、草稿、复制和 `.sql` 导出                                |
| 格式转换 | JSON 格式化与压缩、JSON / YAML 转换、Base64、URL 编解码、时间戳、UUID 等                                            |
| 图片工坊 | 批量处理 JPG / PNG / WebP / BMP / GIF，导出 JPG / PNG / WebP；支持画质调节、等比缩小、透明背景处理和前后对比        |
| Markdown | 编辑、预览、分栏，本地文件打开与保存、草稿及 HTML 导出                                                              |
| 远程连接 | SSH 终端、SFTP 文件管理、调用系统 RDP；密码或私钥认证、凭据保存、终端复制粘贴与报错转 AI 草稿                       |
| 数据库   | MySQL / MariaDB、PostgreSQL、SQLite、Oracle、MongoDB、Redis；对象浏览、查询、分页结果、确认式增删改查、数据导入导出 |
| AI 助手  | 流式对话、报错分析、历史会话管理、图片与文本附件，以及基于自选常用片段的本地知识检索                                |
| 数据看板 | 使用记录统计与大屏展示，另提供 CSV 导入、聚合分析、图表及模板                                                       |
| 历史日志 | 本机使用记录、筛选、分页、CSV / JSON 导出                                                                           |
| 常用片段 | 保存、搜索和复制命令、SQL 与文本；可按需作为 AI 知识来源                                                            |
| 设置     | 中英切换、明暗主题、AI 服务配置、数据位置、备份恢复和开源许可                                                       |

### 连接与数据处理

- **远程连接**：SSH 支持密码和私钥认证；SFTP 支持浏览、上传、下载及小型 UTF-8 文本编辑。首次连接需核对主机指纹。Windows 远程桌面通过系统 `mstsc.exe` 打开，不内嵌 RDP 画面。
- **数据库工作台**：支持可调整大小的查询与结果区域、分页浏览、复制表头及内容或仅复制内容。可导入 CSV / TSV / JSON，导出当前已加载结果为 CSV / TSV / JSON / SQL INSERT。不同数据库的可用操作有所区别。
- **操作确认**：结构化数据库写入、远程文件覆盖保存等敏感操作需要确认。AI 报错分析先生成待发送草稿，不会自动执行终端命令。

## 快速开始

### 使用桌面版

发行附件请查看 [GitHub Releases](https://github.com/UstinianFiee/LiteBox/releases)。若尚未提供所需版本的附件，可按下方步骤从源码运行。

- **Portable EXE**：运行 `LiteBox-<版本>-portable.exe`，无需安装。
- **ZIP**：将压缩包完整解压到可写目录，再运行其中的 `LiteBox.exe`，不要直接在压缩包中启动。

升级前退出应用并备份数据。数据位置可在设置中查看，迁移时保留完整数据目录，不要直接合并覆盖不同来源的数据。

### 从源码启动浏览器预览

建议使用 **Node.js 24 和 npm 11**。当前桌面发行目标为 Windows x64；浏览器模式用于界面与本地工具预览。

```powershell
git clone https://github.com/UstinianFiee/LiteBox.git
cd LiteBox
npm ci
npm run dev:web
```

打开 <http://127.0.0.1:5173/>。保持终端运行，修改代码后页面会热更新；按 `Ctrl+C` 停止服务。

| 运行方式      | 可用范围                                                                               |
| ------------- | -------------------------------------------------------------------------------------- |
| 浏览器预览    | 主题与语言、文本、图片、格式转换、Markdown、片段、日志、看板，以及数据库示例和导入预览 |
| Electron 桌面 | 浏览器功能，以及真实 SSH / SFTP / RDP、数据库连接、AI 请求、系统凭据加密和原生文件操作 |

浏览器预览不连接真实服务器或数据库，也不保存连接密码。浏览器数据与桌面数据互相独立；`localhost` 和 `127.0.0.1` 的浏览器存储也不共享。请通过开发服务访问页面，不要直接打开 `dist/index.html`。

### 从源码启动桌面版

先停止占用开发端口的浏览器预览服务，然后运行：

```powershell
npm run dev
```

也可以运行构建后的前端与 Electron：

```powershell
npm run build
npm start
```

`npm run build` 只检查类型并构建前端，不生成 EXE / ZIP。

### 配置 AI 助手

在「设置 → AI 模型服务」中填写接口基础地址、模型 ID 和 API Key，然后保存配置。

- 接口需要兼容 Chat Completions 流式格式；应用在基础地址后追加 `/chat/completions`。
- 远程接口使用 HTTPS；本机服务可以使用 HTTP。无需鉴权的本机服务可不填 API Key。
- 图片识别需要所选模型支持视觉；支持图片和 UTF-8 文本附件，不直接解析 PDF / Word。
- 常用片段作为知识来源时需要自行选择；检索在本机完成，选中的上下文随提问发送。
- 不附带模型、服务账号或额度。服务商可能收费，发送前请清除密码、令牌及其他敏感内容。

## 数据与隐私

- **本地存储**：桌面配置、草稿、对话和附件等保存在本机，位置可在设置中查看。发行版使用程序旁的 `litebox-data`，源码开发默认使用项目根目录的 `.litebox-data`；浏览器使用独立的本地存储。
- **凭据保护**：API Key、数据库密码及远程凭据使用当前 Windows 用户的系统加密；换电脑或系统账号后可能需要重新输入。普通聊天、草稿和附件并非全部加密存储。
- **备份边界**：普通 JSON 备份不包含密码、密钥或附件原文件。完整迁移前请备份整个数据目录，并妥善保管备份。
- **AI 发送边界**：附件及选中的知识片段经用户发送或确认后交给所配置的服务商；不要把不可信内容当作安全指令。
- **日志与联网**：使用日志不记录密码、SQL / 聊天正文或终端输入；项目不提供遥测或自动更新服务。使用 AI、远程连接和网络数据库时仍会连接相应服务。

不要把 `litebox-data`、`.litebox-data`、私钥、连接凭据或个人备份提交到公开仓库。更多说明见 [安全策略](SECURITY.md)。

## 使用边界

- 图片导出为静态单帧，重新编码不保留原始 EXIF 等元数据；不承诺无损压缩或每张图片都能变小，原图不会被覆盖。
- Markdown 预览经过内容清理，不支持脚本或图片预览。
- 数据库查询编辑器用于只读查询，写入通过独立的确认式表单完成；不提供任意写 SQL 脚本、DDL、迁移、全库备份或 SSH 隧道，不替代完整的数据库管理工具。
- 数据库复制与导出面向当前已加载的结果页，不等同于全量导出；分页也不保证跨页数据处于同一事务快照。
- 远程连接后端同时只维持一个活跃 SSH 会话；不提供内嵌 RDP、递归远程删除或后台无人值守运维。
- 数据看板展示本机操作统计或导入的 CSV，不是实时服务器监控。只连接你拥有或获授权的服务器与数据库。

## 开发与测试

技术栈：**Vue 3 · TypeScript · Vite · Electron**。终端使用 xterm.js，图表使用 ECharts。

```powershell
npm test
npm run test:backend
npm run build
npm run test:desktop
```

桌面集成测试需要图形桌面环境。上面的测试和构建命令不生成发行安装包。

| 命令                | 用途                                 |
| ------------------- | ------------------------------------ |
| `npm run dev:web`   | 浏览器开发与预览                     |
| `npm run dev`       | Electron 开发模式                    |
| `npm run typecheck` | TypeScript 类型检查                  |
| `npm run build`     | 类型检查与前端生产构建               |
| `npm run pack`      | 生成 Windows x64 解包应用目录        |
| `npm run dist`      | 生成 Windows x64 Portable EXE 与 ZIP |

打包产物默认写入 `release/v1.0.0/`，实际输出目录可在 `package.json` 的构建配置中调整。发行包与源码是独立产物，应以对应版本的发布说明为准。

### 项目结构

```text
src/                 Vue 页面、组件、样式与前端逻辑
electron/            桌面主进程、IPC 与连接服务
scripts/             开发、测试与构建脚本
tests/               单元、后端测试与界面回归夹具
docs/                使用、开发与维护文档
build/               应用图标等打包资源
```
