# 工作台、远程凭据与使用日志升级

日期：2026-09-28。本轮功能已按用户新的明确要求纳入 **v1.0.0 EXE / ZIP**；两种发布形式均通过隔离启动和保存检查。

## 本轮功能

1. **默认收起主菜单**：每次启动/刷新从图标栏开始，点击顶部按钮展开；切换页面不会擅自收起。
2. **远程身份验证**：SSH 密码/私钥二选一，支持私钥口令。连接配置中勾选「记住凭据」后持久化。RDP 使用密码，不支持 SSH 私钥。
3. **操作看板**：今日操作、保留操作、活跃模块、失败次数、最近七天趋势、模块排行、最近操作；窗口内大屏模式可用 Escape 退出。原 CSV 导入与模板功能保留。
4. **历史日志**：时间、模块、动作、结果；筛选、搜索、CSV/JSON 导出、确认清空，最多保留 3000 条。
5. **工作台横幅**：代码绘制的 SVG 轻动效，不引入视频/大图依赖。名言中英对照每 8 秒轮换，支持暂停/手动切换，悬停/聚焦、标签隐藏或系统减少动画时暂停。英文为应用内译文。
6. **AI 页面**：会话分组/搜索、可收起会话栏、大输入框、四种模式、消息复制、流式停止；输入法选词回车不发送。

## 凭据保存与安全边界

- 普通配置只存服务器地址、用户、认证方式等，不存秘密。
- `remote-secrets.json` 中的密码，或私钥**内容与口令**由桌面主进程用 OS safeStorage 加密。系统加密不可用时拒绝保存，不回退明文。
- 密文绑定连接类型、地址、端口、用户名及认证方式；修改目标后不会自动把旧凭据发送到新目标。配置 ID 对应保存项，不在渲染器显示已保存的密码/私钥。
- 相同连接留空可继续使用保存项；「忘记已存凭据」清除保存项。私钥首次选择必须通过原生文件对话框授权，最大 128 KiB；加密保存后不依赖原文件路径。
- 保存的凭据不包含在普通配置备份中；换机器/系统用户需重新配置。不要把整个数据目录当成无敏感信息的文件分享。
- RDP 将密码转换为 Windows DPAPI 密文放入临时 `.rdp` 文件，不通过命令参数/环境变量传递明文；mstsc 退出后清理该文件。异常退出可能残留加密文件。
- 已验证 DPAPI 加解密往返，但未登录真实 RDP 服务器；服务器策略可能仍要求输入密码。
- 浏览器预览禁用凭据输入/保存，真实连接需运行未打包 Electron。最多 8 个资产标签不等于 8 条同时活跃 SSH；当前后端仅允许一个活跃 SSH 连接。

## 日志范围

- 桌面文件：`activity-log.json`；浏览器：当前站点本地存储，二者独立。
- 记录应用启动、页面访问、主要本地工具完成、复制/文件操作、备份、AI 请求、SSH/RDP/数据库连接、数据库查询/写入、SFTP 传输和凭据操作。
- 只保存枚举元数据和时间/ID；不存主机地址、文件路径、错误正文、密码、私钥、聊天内容、SQL、终端输入、文档内容。
- 通用文件/剪贴板事件标为「应用」；不记录所有输入、草稿自动保存、配置字段修改，不是合规审计系统。
- 操作统计排除启动与页面访问，基于当前保留记录，不是全生命周期累计；旧版本操作明细不会伪造补齐。
- 读取损坏日志时保留原文件并报错，不自动覆盖。日志写失败不把已成功提交的数据库操作报成执行失败。
- 导出只包含当前筛选的元数据，清空需要确认。日志本身未整库加密，仅留本机，不自动上传。
