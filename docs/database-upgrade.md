## 启动与验证

在项目目录运行：

```powershell
npm run dev:web
```

打开 `http://127.0.0.1:5173/`。已有预览服务时直接刷新，不重复启动。
浏览器支持界面预览、示例结果复制及本地数据转换；真实数据库连接、密码保险库及写入必须在桌面端使用。

验证原生能力时，先在启动预览的终端按 Ctrl+C 停止服务，再运行：

```powershell
npm run dev
```

这是未打包的 Electron 开发模式，不会生成发行包。

## 连接类型

| 数据库 | 默认端口 | 填写说明 |
| --- | --- | --- |
| MySQL / MariaDB | 3306 | 主机、用户名、数据库 |
| PostgreSQL | 5432 | 数据库默认 postgres |
| SQLite | — | 使用文件选择器授权现有数据库文件 |
| Oracle | 1521 | 填写 Service Name，例如 FREEPDB1；使用 Thin 驱动 |
| MongoDB | 27017 | 业务数据库默认 test；认证数据库默认 admin |
| Redis | 6379 | 数据库索引默认 0；支持可选 ACL 用户名 |

Oracle 当前显示登录用户所属表；LOB / 二进制结果显示占位符，不作为完整数据导出。MongoDB 当前使用主机 / 端口方式，不提供完整连接 URI / 集群配置界面。

MongoDB 查询示例：

```json
{"action":"find","collection":"orders","filter":{},"limit":200}
```

MongoDB 文档使用 Extended JSON 表示 ObjectId 等特殊类型。
Redis 使用命令 JSON 数组，例如：

```json
["GET", "order:1001"]
```

Redis 只读命令包括 GET、MGET、TYPE、TTL、EXISTS、HGET、LRANGE、SCAN；不是任意命令控制台。SCAN 返回游标，不保证一次列出全部键。

## 保存密码

在连接弹窗勾选记住密码并保存。密码由主进程通过操作系统加密，单独存储，不写入普通连接配置、浏览器存储或配置备份，也不会回传明文到页面。下次密码留空即可使用已保存凭据；可通过忘记密码清除。

凭据绑定连接目标，修改主机、端口、用户名等后需重新保存。加密凭据依赖当前系统账户，复制到其他设备或账户不保证可解密；系统加密不可用时拒绝保存，不降级为明文。这并不表示全部本地数据都已加密。

## 复制、导入与导出

- 查询结果提供「复制表头 + 内容」与「仅复制内容」，以制表符分隔，便于粘贴到表格。
- 导出 CSV、TSV、JSON；选中关系型表后还可导出 SQL INSERT。导出的仅是当前已加载结果，不是全库备份。
- 导入支持 CSV、TSV、JSON，最大 2 MiB / 500 条。文件先解析和预览，**不会因选择文件自动写入**。弹窗可下载 JSON 示例模板。
- CSV / TSV 第一行必须为不重复的字段名；空单元格按空字符串处理。含 NULL 或大数的精确交换优先使用 JSON；大数及高精度数应加引号，MongoDB 可使用 Extended JSON。
- JSON 支持对象数组以及工作台导出的 `{ "columns": [...], "rows": [...] }` 格式。重复列名可保留用于查看，但不能直接映射为插入字段。
- CSV / TSV 导出防护表格公式；SQL 导出按文本引用值，执行前核对目标字段类型。暂不支持 XLSX 导入导出或 SQL 脚本导入执行。

CSV 示例（字段须与目标表一致）：

```csv
id,order_no,status
1,T2214-260921004,pending
```

## 增删改查与安全边界

查询编辑器保持只读。新增 / 导入、更新、删除通过专用数据操作弹窗提交：选择目标表或集合 → 编辑 JSON → 勾选确认 → 系统原生二次确认。

- 关系型数据库：参数绑定、事务写入，单次最多 500 行；超出回滚。MySQL 写入要求 InnoDB。
- 更新和删除必须提供非空条件，不提供一键清空表。
- MongoDB：一次新增、更新或删除一个文档；更新 / 删除拒绝匹配多文档的条件。暂不支持批量导入。
- Redis：一次处理一个字符串键；新增不得覆盖已有键，修改要求键已存在并保留 TTL，删除针对指定键。暂不提供所有数据结构的编辑器。
- 成功写入后清除旧结果，重新查询确认真实数据。
- **取消 / 超时可能发生在远端提交之后，不能保证写入被撤销；务必核对数据后再重试。**

查询结果最多 1000 行 / 2 MiB。请使用最小权限账户；只读语句过滤不等同于数据库安全沙箱。生产库操作前先备份。暂不提供 DDL、任意写 SQL、SSH 隧道或完整 Navicat 功能。
